## 2. Core Components

### 2.1. Live Telemetry Console (`app/live/page.tsx`)
- **Purpose:** Central command center for active Grand Prix weekends.
- **Session Timetable:** Displays the 4 competitive sessions (`Sprint Qualifying`, `Sprint Race`, `Qualifying`, `Grand Prix`) with dates, start times, and real-time status badges (`LIVE NOW`, `UPCOMING`, `CONCLUDED`, `NOT SCHEDULED`).
- **Timing Classification Tower:** Displays driver positions, numbers, team color indicators, gaps, intervals, sector benchmarks, speed traps, Pirelli compound badges, tyre age, and pit counts.
- **Mission Control Feed:** Auto-scrolling terminal capturing genuine FIA Race Control notices, flag condition changes (`GREEN`, `YELLOW`, `SAFETY CAR`, `RED FLAG`), and pit-wall uplink status.

### 2.2. Interactive Circuit Radar (`app/components/CircuitMap.tsx` & `app/lib/circuitTransform.ts`)
- **Coverage:** 78 Formula 1 circuits (25 current calendar tracks + 53 historic circuits) spanning 4,348 corners.
- **Geometry Pipeline:**
  - `computeTransformBounds`: Determines bounding boxes and auto-settles circuits with upright aspect ratios (`rangeY > rangeX * 1.15`) by rotating 90° clockwise.
  - `transformCorners`: Implements a 5-pass iterative collision relaxation algorithm (`MIN_LABEL_DISTANCE = 38px`) to prevent badge collisions in tight chicanes (e.g. Monza T1–2, T4–5).
  - SVG Anchor Stability: Prevents hover jitter by strictly avoiding `transformOrigin: center` on dynamic translated nodes.

### 2.3. Telemetry Proxy Daemon (`scripts/f1-proxy.js`)
- **Port:** Local WebSocket server on `ws://localhost:8080`.
- **Protocol:** HTTP POST negotiation with `livetiming.formula1.com/signalrcore/negotiate`, WebSocket tunnel connection, and raw Base64/Gzip decompression.
- **Data Channels:** Relays `TimingData`, `TrackStatus`, `RaceControlMessages`, `SessionInfo`, and `WeatherData`.

### 2.4. Authentication & Personalization (`app/lib/jwt.ts` & `app/components/AuthGate.tsx`)
- **Auth Provider:** Supabase Auth with PKCE flow and Google OAuth 2.0.
- **Session Security:** Web Crypto HS256 JWT tokens persisted in `HttpOnly; Secure; SameSite=Lax` cookies (`paddock_auth_token`), preventing client-side script inspection.
- **Constructor Themes:** Dynamic CSS variable injection supporting all 10 constructor palettes and high-resolution pit-wall wallpapers.

## 3. Data Flow

1. **Calendar & Track Initialization:**
   - On mount, `loadCalendar()` fetches `${API_BASE}/current.json`.
   - Resolves active Grand Prix, populates 4 competitive sessions, and anchors initial roster lap times based on the venue's lap record (`getVenueBaseLapTime`).
2. **Pit-Wall Live Stream Connection:**
   - `connectWebSocket()` binds to `ws://localhost:8080`.
   - The proxy negotiates with F1 SignalR servers and broadcasts `F1_LIVE_SERVER` frames to connected browser clients.
3. **Telemetry Packet Ingestion:**
   - `TimingData.Lines` updates position, lap times, speed traps, pit status, and gaps in `setDrivers`.
   - `TrackStatus` updates track flag conditions (`GREEN`, `YELLOW`, `SAFETY CAR`, `RED FLAG`).
   - `RaceControlMessages` appends official FIA messages to Mission Control.
4. **Standby Mode:**
   - If no competitive session is underway, the classification board displays a stable venue benchmark grid, and the countdown clock ticks toward the next scheduled session.

## 4. Technical Debt & Conventions

### 4.1. Conventions
- **Language & Runtime:** TypeScript 5 in strict mode. All Next.js page components default to React Server Components unless interactive pit-wall hooks require `'use client'`.
- **CSS & Theming:** Use CSS custom properties defined in `app/globals.css` (`var(--carbon-1)`, `var(--line)`, `var(--red)`, `var(--cyan)`). Avoid hardcoded hex colors when design tokens exist.
- **Click vs. Pan Guard:** Interactive SVG canvas elements must use `data-corner="true"` and an opening guard threshold (`modalOpenedAtRef >= 250ms`) to isolate clicks from dragging.

### 4.2. Technical Debt / Optimization Opportunities
- [ ] **Cloud Proxy Deployment:** Deploy `scripts/f1-proxy.js` as an independent cloud service (e.g. Fly.io or ECS container) with TLS WebSocket endpoints (`wss://`) for zero-configuration client connectivity.
- [ ] **Historical Telemetry Cache:** Implement an indexed Redis or Supabase cache layer for historical lap telemetry to reduce Jolpica Ergast rate limits during replay sessions.
- [ ] **Corner Geometry Chunking:** Splitting `circuitCornersData.ts` (~441KB) into dynamic per-circuit chunks to reduce the initial JavaScript bundle size.
